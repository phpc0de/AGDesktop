# Q2：有下载记录的视频看不出标记 → 金暗双圈描边

## 根因链（file:line）

- 双徽章系统并存：`SexCat::Badge`（sexcat_badge.cpp，下载记录徽章，photo/document/grouped 三视图有画）与 `ayuDownloadedBadge`（gif.cpp 本地实现，底板对勾）互不相认。
- **Gif 视图（= 视频播放态/GIF/圆视视频）从未画 SexCat 徽章**；它画的 ayu 徽章被四道闸门卡死，其中 `IsDownloadedDocument` 基于会话内存 set（save_hook.cpp:1203-1218）**重启即空** → 视频"未加载+不在媒体缓存+本会话没下过"时有记录也不画——"有些视频"的成因。
- 圆视视频被 `!isRound` 永久排除；同一视频缩略图态/播放态外观还会切换。
- 旧角标 chip 叠在媒体上无衬底，同色系帧上不可读。

## 改动（提交 2da806ebad）

- 标记视觉 = **金 `#f2b544` 内圈 2px + 暗 `#1f1f1f` 外圈 1px 双圈描边**（用户拍板"金闪闪"+单色会融的修正；外圈职责 = 把金圈从任何亮/花/同色帧上剥离）；样式变量进 `sexcat.style`，随界面缩放。
- `PaintBadge(p, peer, msg, mediaRect, frameRadius, refresh)`：双圈 OddEven 填充描边，radius<0 = 圆视椭圆环；DB 缓存查询/悬停 tooltip 机制不变。
- Gif 视图补画 + `Gif::textState` 悬停 tooltip（照 photo 模式）→ **重启后照显**（走 DB 缓存，不再依赖内存 set）。
- 旧对勾让位：仅当无下载记录且本地已下载时才画（gif.cpp）。
- 清理：旧 chip 样式变量、`IsHovered` 死 API 删除。

## 外部构建机手测清单

1. 亮帧/暗帧/花色视频各一条（有下载记录）→ 播放态与缩略图态都应显示金暗双圈，任何帧不融色。
2. 视频通话圆形消息（圆视）有记录 → 椭圆双圈显示。
3. 重启应用（媒体缓存不加载该视频）→ 记录仍在 → 边框仍显示（原内存 set 漏洞修复验证）。
4. GIF/WebM 有记录 → 边框显示。
5. 相册组图（grouped）每格边框、圆角贴合。
6. 悬停边框右上角 → tooltip 显示保存路径；移开恢复。
7. 无记录但本地已下载的视频 → 旧对勾徽章仍显示（让位闸门验证）。
8. 有记录的视频 → 不再出现旧对勾（不重叠）。
9. 剧透/TTL 消息 → 边框不泄露。
10. 多选/长按选中态 → 金圈仍可辨。
