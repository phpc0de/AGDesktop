# v7.2.9-ayu.40

## 下载历史：消息已删的旧名重建
- 修复"命名永远修不好"的最后一个死洞：消息已删除的旧格式名（`#tags` 居首）此前永远无法重建——命名幂等检查依赖消息的简介与标签，消息一删就恒等通过、恒不改名。现在直接从文件名本身重建：开头 `#tag` 连串剥进尾部 tags 段、其余作原始名段，产出真语法名且形状幂等。
- 修复"repair skipped, missing"假报：超长或含特殊字符的路径 Windows 常规方式探测不到，会把磁盘上真实存在的文件报成缺失（最需要修复的恰恰修不到）。存在性判定失败时退回 Win32 原生命名空间确认。
- 修复日志可归因：每次改名记录 `旧名 -> 新名 (来源分支)`（doc=服务端原名 / legacy=文件名重建 / wrap=带简介重包 / clean=清理名）；missing 日志每条记录每次启动只打一次，不再刷屏。
