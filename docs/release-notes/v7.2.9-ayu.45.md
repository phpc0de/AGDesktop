# v7.2.9-ayu.45

## 修复：下载历史行消失（灰色行下完后蒸发）
- 根因：下载完成的瞬间，一个后台清理步骤抢在"落库"之前把下载起点标记删掉了，落库逻辑扑空——于是这条下载的历史行（下载中显示为灰色）被删除且不再重建，表现为"下载完成后历史消失"。新下载的内容同样命中。
- 现在：完成的下载由真正的落库流程接管标记；只有手动取消的下载才立即清理标记（防止标记泄漏导致之后同位置下载被误判去重）。已完成的下载不再丢历史行。

## 新增：置顶本地优先，不再被服务器同步恢复
- 以前取消置顶（或本地置顶）后，服务器的对话框同步会把置顶状态改回去。
- 现在你对某个会话的置顶/取消置顶是本地最终决定，保存在 ayu.json，每次同步后强制维持；仅对你手动操作过的会话生效，其余会话仍完全跟随服务器。

## 新增：标签拉黑 → 聊天图片/视频自动模糊
- 在 Sow list（ sow 列表）窗口右键某个标签：新增 "Blacklist tag"；已拉黑的标签显示 "Remove from blacklist"。右键空白区可查看已拉黑标签并逐个移除。
- 聊天里凡是说明文字（caption）包含被拉黑标签（不区分大小写）的图片/视频/相册/贴纸，自动套用敏感内容式模糊遮罩，标牌两行显示：第一行 "Sensitive content"，第二行显示命中的 `#标签名`，点击可查看。
- 与隐身模式、付费内容标牌互不影响；数据保存在 sexcat 库新表 blocked_tag。
