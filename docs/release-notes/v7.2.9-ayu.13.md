# v7.2.9-ayu.13

## Fixed
- devtools 封包解码两大错位根因：254 长格式字节段少跳 1 word；`flags.N?true` 置位字段未消费线上 boolTrue word。此后字段对齐不再错乱，未知 ctor 大幅减少。
- devtools 未知 ctor 裸数据新增 `text: "..."` ASCII 预览，一眼看出本质是字符串的值。
- devtools 列表：新包到达不再强制跳底——未在底部时保持当前位置，已选中条目保持选中；右侧详情内容不变时不再重置（不再丢阅读位置）。
- Copy All：超长条目（>24K）改为从原始数据全量重解码后复制，总上限 1.5M 字符，不再只给截断版。
- 视频/文件状态行覆盖面放宽：任何有时长且非贴纸/语音/音频的文档都显示 时长 + 大小 + 分辨率徽章（此前仅 isVideoFile 分支显示，"部分视频"不显示即此因）。
- 改名/移动已入库文件：sidecar（.sexcat.json）随文件迁移到新位置；未命中 DB 时记录 shell watch 日志便于诊断。
- 哈希上限 512MB → 16GB：几 GB 的视频现在也会计算 sha，同 sha 关联/去重功能对大文件生效。
