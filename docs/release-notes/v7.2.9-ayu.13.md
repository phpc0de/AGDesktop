# v7.2.9-ayu.13

## Added
- 转发梯子新增"重挂载"档：直发被拒后先用消息内已有的 file_id/access_hash/file_reference 通过 sendMedia 服务端复制媒体（零下载零上传），全部媒体成功即完成；仅当存在无法重挂载的条目才落到下载重传档。
- "实验新转发"开关（设置→文件夹筛选，默认关）：关闭时直发失败后不再自动下载重传；开启时收发的每个封包解码内容写入 `mtpdump` 日志（access_hash 打码、[名字]注记剔除）。
- checkpoint 明文导出：每次打点同步追加一行 JSON 到 `tdata/checkpoints.jsonl`（时间/会话 id/话题/消息 id/群名），不加密随时可读。
- 聊天行强制文件夹标签：设置里的 force 开关现在真实作用于聊天列表（无视 tagsEnabled、单文件夹也显示）。
- 顶栏限制状态色条：受限频道在顶栏底部显示 2px 色条（红=banned、橙=noforwards），比纯标题变色醒目。

## Fixed
- devtools 封包解码两大错位根因：254 长格式字节段少跳 1 word；`flags.N?true` 置位字段未消费线上 boolTrue word。此后字段对齐不再错乱，未知 ctor 大幅减少。
- devtools 未知 ctor 裸数据新增 `text: "..."` ASCII 预览，一眼看出本质是字符串的值。
- devtools 列表：新包到达不再强制跳底——未在底部时保持当前位置，已选中条目保持选中；右侧详情内容不变时不再重置（不再丢阅读位置）。
- Copy All：超长条目（>24K）改为从原始数据全量重解码后复制，总上限 1.5M 字符，不再只给截断版。
- 视频/文件状态行覆盖面放宽：任何有时长且非贴纸/语音/音频的文档都显示 时长 + 大小 + 分辨率徽章（此前仅 isVideoFile 分支显示，"部分视频"不显示即此因）。
- 改名/移动已入库文件：sidecar（.sexcat.json）随文件迁移到新位置；未命中 DB 时记录 shell watch 日志便于诊断。
- 哈希上限 512MB → 16GB：几 GB 的视频现在也会计算 sha，同 sha 关联/去重功能对大文件生效。

## Known Limits
- 同 sha 下载跳过 / 聊天内下载徽章 / 同 sha 标记：需要"下载流中边下边算 sha 并中止"设计，下一轮实现。
- 批量多选下载、checkpoint 列表、母猪列表：下一轮。
- 重挂载档按条目直发，相册结构不保证还原；file_reference 过期时该条目落到下载重传档。
