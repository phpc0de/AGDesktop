# v7.2.9-ayu.25

## Fixed
- .24 下载改名回归（自定义下载路径场景）：相册批量下载/挑选下载把"文件夹名+原名"拼成一个合并文件名、文件错位到上级目录，增补名整体失效。快速路径出口统一补尾斜杠，批量造名 join 改 `QDir().filePath` 归一化。
- 增补触发门从"原始名主干全数字"放宽为"消息带 tag/简介即增补"：服务器下发的任意文件名（含字母、非纯数字）都参与 `#tags -描述-原名` 改名，原名恒为尾段；幂等守卫防止名字已带前缀时二次堆叠。
- "每次询问下载位置"开启时，单条保存的对话框默认名恢复为增补名（此前只有"另存为"模式注入，快存对话框显示裸原名）。
- 落盘后改名失败（Windows 句柄占用等）从静默日志升级为 toast 提示，不再无声丢名。
- 重下已存过的文件被去重跳过时，库里旧裸名文件就地改名并重挂记录：重下即自愈，不再保留旧构建时代的裸名遗留文件。

## Known Limits
- 下载进行中命中改名注入时，可能按 upstream 语义取消并重启下载（产出增补名，代价是重复流量）。
- 服务器名恰好以 "#tag" 开头时，幂等守卫会保守跳过增补。
- 本地标签/检查点标记为纯本机功能，官方客户端不可见。

## Internal
- 编译错误静态审计（`e32d3d8748..HEAD`）：符号存在性与签名三方一致、匿名命名空间可见性顺序、常量正确性、MSVC 三件套（C2663/C2039/C2653 类）、lang codegen 约束、行尾与 BOM 全部核验通过，0 编译错误。
