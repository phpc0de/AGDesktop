# Release Notes — v7.2.9-ayu.10

基于上游 v7.2.9 + AyuGram 功能层。Tag：`v7.2.9-ayu.10`（head `cb52769657`）。

## 下载

- 产物：`AyuGram_7.2.9-ayu.10_win64_portable.zip`（单可执行文件，解压即用）
- 校验：`sha256sums.txt`
- 构建：GitHub Actions（windows-2022 / MSVC v143 / Qt 5.15.19 静态）

## 新增（Added）

- **SexCat 下载溯源套件**（专属数据目录 `tdata/sexcat/`，独立 `sexcat.db`，与 AyuGram 的 ayudata 完全隔离）：
  - **下载溯源**：手动"另存为"成功的每个文件自动记录——内容 SHA-256、来源消息（对话标题快照，源会话被删仍可读）、时间、路径。只记录显式另存，自动下载零改动；文档经统一保存漏斗，照片/视频/相册/批量保存各有独立入口，媒体查看器直写分支也覆盖。
  - **SHA 零运算复用**：哈希只在保存时算一次，写入 NTFS 备用数据流（`文件:sexcat.sha`）——改名/移动后跟随文件，零成本命中；非 NTFS 自动降级同名侧车 `.sexcat.json`；都没有才后台补算（串行限速队列，>512MB 拒绝并记日志）。
  - **聊天气泡"已保存"徽标**：曾另存过的消息媒体右上角 14px 角标（浅色、hover 亮起），消息级 LRU 缓存 + 异步查询，渐进出现不占位；hover 显示保存路径，右键菜单：打开所在文件夹 / 查看下载历史 / 重新验证。
  - **保存成功提示**：另存 + 记录完成后浅色 toast"已保存 · 来源已记录"，3 秒。
  - **下载历史窗口**：时间 / 文件名 / 来源（可点击跳转高亮到原消息）/ 当前路径四列；对话过滤 + 关键词搜索；丢失文件置灰标记；重新定位（选新路径→哈希校验→回写 ADS）；批量"验证选中"（哈希比对，不一致标红）。
  - **设置**：AyuGram 设置新增 SexCat 节——总开关（默认开，关闭即停记录+隐藏徽标）与历史窗口入口。
- **Releases 页自动 changelog**：发布流程改为读取 `docs/release-notes/<tag>.md` 作为发布正文（上一版已生效，本页即产物）。

## 修复（Fixed）

- **启动断言 `!_accounts.empty()`**：MTP devtools 解码/重放路径在账户注册前读取活动账户导致启动即崩；改按上游模式以 `domain.started()` 守卫（v7.2.9-ayu.9 已含，随本次构建首次随正常发布上线）。

## 已知限制（Known Limits）

- 本套件之前的旧下载没有哈希记录，无法被"重新定位/验证"链路对应（可用历史窗口"验证"提示"无记录"）。
- exFAT/FAT32 无 NTFS ADS，走侧车文件；侧车与文件分离移动后需手动"重新定位"重连。
- 记录未含账号维度：跳转解析取第一个持有该对话的账号。
- zh-hans 翻译随上游翻译平台同步，新 key 首版可能显示英文。
