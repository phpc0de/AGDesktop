# v7.2.9-ayu.24

## Added
- 保存媒体金色描边标记：sexcat 已记录的图片/视频/分组媒体四周金+暗双圈细描边（圆视视频为环形），任何底色内容都可辨识；悬停显示文件名 tooltip；旧 ayu 已下载对勾让位给 sexcat 记录。
- 下载历史丢失记录自动找回三件套：窗口打开时扫描候选目录批量回填；全盘 shell 监听捕获移动/改名（同卷移动即改名场景）；应用启动时按已知目录补一轮救援。
- 下载页顶栏"取消全部下载"常显：不再等有任务进行中才出现；批量下载启动时 toast 提示该入口。
- 图片消息自动重命名：批量/多选保存图片走 `#tags -描述-photo_N.jpg` 增补名（photo_N 尾段保留唯一性）。

## Changed
- 无有效命名的文档改用兜底名参与增补：服务器未下发名字的视频以 `<文档id><扩展名>` 作原始名，增补门必触发（如 `6.mp4` → `#抖音-哈哈哈-6.mp4`）；批量/相册挑选两处造名统一走兜底名，空名不再退化成目录路径。
- `BuildAugmentedName` 空 original 守卫：任何流程都不会再产出缺原始名段的增补名。

## Fixed
- 静默受限频道（收到内容但不显示限制提示）同样套用红色 tint，此前仅显式受限生效。
- 聊天列表本地标签 chip 残留裁切与行高不刷新：解除高度刷新门，重绘按新内容刷新。
- 下载历史丢失记录手动找回改为按文件指认：灰色行右键 Relocate 选中文件即回填路径，不再要求目录逐个试。
- 批量快速保存已缓存视频原先静默零动作（不落盘、不进下载历史）：现直接写入默认下载目录并完整记录，已看过的视频批量保存后历史不再缺行。
- 单条保存缓存数据直写分支补记录：与未缓存路径语义对齐，不再漏记。

## Known Limits
- "增补名丢原始名段"形状出自旧构建的半实现中间态，需从本版（`9d3c146463` 及之后）重建验证。
- 单条快速保存已缓存文件仍走缓存零动作分支（upstream 语义，改动半径大，待单独立项）。
- 跨盘移动文件 shell 通知无法捕获，仍需下载历史右键 Relocate 指认一次。
- 本地标签/检查点标记为纯本机功能，官方客户端不可见。

## Internal
- CI 实测补修（第二轮）：`FallbackDocumentName` 对 const QString 调用非 const replace（C2663）改拷贝后替换；`document->loaded()` 不存在（C2039）改用 `filepath(true)` 缓存判定；`history_widget` 静默受限标记处未限定的 `PeerUpdateFlag::UnavailableReason`（C2653）改 `Data::PeerUpdate::Flag::UnavailableReason`。
- CI 实测补修：sexcat.style 裸十六进制色移入 C++ 常量（style codegen 204：非 palette 模块禁 hex）；`lng_sexcat_autorelocate_done` 的 `{count}` 改 `{num}`（lang codegen 806：count 保留给复数键）。
- 记录契约澄清：直写路径的记录由 `MarkDocumentSaveAs` pending → `DocumentData::save` 瞬时写分支自带 `NotifyDocumentSaved` 全覆盖；写点再显式调 `RecordSaveAttempt` 会双记录（已避免）。
- 批量保存快速路径 `quickPath` 三处收敛（saveImages 复用 / saveDocuments / savePicked 各自解析）。
