# v7.2.9-ayu.26

## Added
- 存档列表（下载历史）按消息分组展示：组头 = 来源标题 · N 个文件 · 总大小（含丢失数后缀），默认展开、可折叠；无来源记录归 "No source" 组；丢失行并入各自消息组（原底部"丢失大组"取消）。
- 组头左键 = 全选/取消全选组内文件；组头右键新增 "Delete group records" / "Delete group records and files"；单行右键新增对称的 "Delete record" / "Delete record and file"。
- 删除确认框列出条数与总大小；删除文件时每次询问"移入回收站 / 永久删除"；toast 如实报告记录与文件的实际删除数。删除记录连带清空来源标签（孤儿标签自动消失），文件连同 .sexcat.json 侧车一起清理。
- 相册右键菜单视频化：相册两个下载动作与视频挑选器只收视频（"Download all videos" / "Save all videos to folder..."），混合相册不再连图片一起下载；纯图片相册补 "Download all photos" 图片快存入口。
- 来源标签多对多：一条记录可挂多个 #tag（新 source_tag 表，旧库自动建表 + 一次性回填，零迁移）。消息带多个 hashtag 时全部入库（此前只记第一个）；标签候选、聚合统计、重命名/删除标签均按多标签语义；批量保存整批共用同一组标签。
- 跨盘移动自动回链：shell 监听增订阅 CREATE 事件，文件落到新盘即按 NTFS ADS 哈希自动重挂丢失记录（此前跨盘移动后记录路径永久失效）；自动救援扫描扩全部固定盘（旧盘候选优先，预算耗尽自然跳过）。
- 丢失文件批量找回：丢失行右键 "Relocate all lost files in folder..." → 选目录一次回链全部丢失记录，toast 报告回链数。

## Fixed
- 快速保存的图片此前完全不落存档记录，现与文件夹保存同样记录（图片入口的标签承诺随之兑现）。

## Known Limits
- 单个文件删除失败（句柄被占用）时记录仍被清除、toast 计数如实反映，残留文件需手动清理。
- 丢失救援扫描窗口仍为最近 2000 条，更老记录无救援。
- "复制"（非移动）出的新副本不回链，走既有新增记录语义；CREATE 实时回链的代价是全系统文件创建事件各做一次轻量 ADS 读。
- 组头文案 "No source" / "· M lost" 暂未本地化。

## Internal
- 编译错误静态审计（f46cd36..HEAD，三文件簇并行、sqlite_orm 对照内置头逐条验证）：0 编译错误；2 个阻断点（恢复下载路径漏迁移 QString→QStringList 签名、4 个非复数 lang 键误用复数保留占位符 {count}）已在发布前修复（e765684bed）。
- 用户报的偶发启动失败（FATAL: Could not move logging）诊断为上游单实例×日志轮转竞态：旧实例退出窗口内连发多进程、次实例仍握启动日志句柄时新主实例改名失败 → 失败窗，重试即开，无数据风险；修复方案挂账。
