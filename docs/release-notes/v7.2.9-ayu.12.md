# Release Notes — v7.2.9-ayu.12

基于上游 v7.2.9 + AyuGram 功能层。Tag：`v7.2.9-ayu.12`。
本版聚焦反馈轮 2：MTP Devtools 解码纠错、解锁转发主线程卡死修复、文件夹标签本地强制、SexCat 留痕体验补齐。

## 下载

- 产物：`AyuGram_7.2.9-ayu.12_win64_portable.zip`（单可执行文件，解压即用）
- 校验：`sha256sums.txt`
- 构建：GitHub Actions（windows-2022 / MSVC v143 / Qt 5.15.19 静态）

## 新增（Added）

- **MTP Devtools 包辅助解读（反馈 9/11/16/32/33/34/35/36）**：
  - 修复 vector 构造 id 写反（`0x15c4b51c` → `0x1cb5c415`）与双跳过 bug：`updates.channelDifference` 等 2400+ 字节的包现在完整解码，不再出现 `<not a vector, skipped>` 与海量 trailing primes；`file_reference` 等字段随之可见。
  - 生成器找回 137 个短 id 构造（如 `updates.getChannelDifference`、`messages.sendMedia`）：之前显示 `ctor_0x03173d78 { raw: … }` 的包现在按真实构造解析。
  - 新增 35 条常用构造的中文用途/字段注释，直接渲染在解码树里（`updates.getDifference`、`messages.sendMultiMedia`、`upload.getFile`、MTProto 信封等）。
  - id 标注增强：`from_id`、`inviter_id`、泛型 `id`、vector 元素内的 id 都会尝试标注 `[对端名称]`。
  - `bytes` 字段显示长度与可打印预览（`bytes[<N>]: 0x…`）；photo/document 构造追加一行摘要（`// [photo id=.. size=.. WxH]`）。
  - Edit & Replay 编辑器实时预览：改 TL 文本 300ms 后自动重新解码，错误原因就地显示。
  - 新增 "Copy all" 一键复制当前过滤列表全部包内容。
- **SexCat 留痕（反馈 20/23/24/25/27）**：
  - 保存 AG 检查点成功后弹 3 秒浅色 toast 确认。
  - 聊天顶栏新增"下载历史"按钮（位于检查点跳转按钮与搜索之间）。
  - 下载历史窗口新增 SHA-256 列（缩略显示 + tooltip 全量）与右键 "Copy SHA-256"。
  - 新增 "Select all" 全选按钮（Ctrl/Shift 多选本就可用）。
  - 普通下载（下载按钮/媒体查看器）完成后同样记录并点亮气泡徽标（按路径+大小去重）。
- **受限频道直观提示**（反馈 37）：已拍板形态=顶栏标题变色并区分限制类型（内容保护/封禁频道），下一版实施；本轮完成标志与渲染点调查。

## 修复（Fixed）

- **解锁转发"未响应"卡死（反馈 2）**：zero-cost 被服务端拒绝后的完整重传回退没有切到工作线程，整条下载重传链（含最长 5/15 分钟的同步等待）跑在主线程，UI 假死。现在回退与 `applyUpdates` 均按线程约束调度；闩锁超时全部落日志（`tdata/logs/ayu-*.log`，tag=forward）。
- **文件夹标签强制开关被覆盖（反馈 6）**：force 模式下不再发送 `messages.toggleDialogFilterTags`（此前每次拨动都发并被服务器 403 `PREMIUM_ACCOUNT_REQUIRED` 打回），开关状态与显示全部走本地，登录重载不再回绕。
- **SexCat 扫描"没有结果"（反馈 26/28）**：NTFS 同卷移动的文件带着 ADS 标记走，扫描时被误判"已标记"跳过，丢失记录永远无法重链。现在先按哈希查库，命中丢失记录直接改链到新路径。

## 已知限制（Known Limits）

- 受保护内容的 0 成本引用重发已被服务器全面强制校验（`CHAT_FORWARDS_RESTRICTED`），转发必然走"下载-重传"通道——大文件转发耗时取决于带宽，属预期行为。
- 文件夹标签：非 premium 账号服务器不下发标签颜色（`f_color`），force 只保证开关可保持、不回弹；彩色标签 chip 仍需 premium 数据。
- 下载监听在首次媒体绘制/保存/打开历史窗口时武装：应用刚启动数秒内完成的极快下载可能漏记，重启后由恢复条目补齐。
- 下载完成的记录对超过 512MB 的文件不做哈希（沿用既有上限）。
