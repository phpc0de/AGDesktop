# v7.2.9-ayu.36

## 命名语法重做（原始名居首）
- 文件名统一为 `原始名 - 简介 - #标签.扩展名`：原始名永远在最前，扩展名永远钉在最后；简介长度按所在目录深度自适应裁剪，任何极端情况都不会放弃或截出坏名。
- emoji 不再被截断出"找不到文件"的坏名（此前部分文件能下载但播放/重命名全部失败）。
- 频道文案样板剔除保留：来源:、加入我的频道 @xx、更多完整版、点击置顶/点击提取、裸链接、标题: 标签。

## 重复保存自愈
- 对已保存过的消息再次保存时，不再只提示"已在库中"——旧文件当场按新语法就地改名（含批量下载被跳过的场景），并弹提示显示新文件名。

## 下载历史坏名自动修复与旧名迁移
- 打开下载历史自动扫描：播放/重命名报"找不到文件"的坏名自动改名修复，弹窗报修复数量。
- 旧版本落盘的 `#标签` 开头老格式名自动迁成 `原始名 - 简介 - 标签` 新格式（消息还在时取回真实原始名）；迁移一次性完成，重复打开不再变动。
