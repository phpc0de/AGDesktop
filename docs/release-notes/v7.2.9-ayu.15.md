# v7.2.9-ayu.15

## Added
- 顶栏新增"跳转到未读"显式按钮（未读书图标），始终定位到未读分隔线，不再依赖右下角 ↓ 的行为。
- 消息底部时间旁新增消息种类标记：🎬视频 🎥圆片视频 🌀GIF 🎙语音 🎵音乐 📎文件 📷图片（直接以表情前缀渲染，两种底部信息样式都生效）。
- 聊天分组标记支持自定义文字：右键分组标记子菜单新增"Set mark text…/Clear mark text"，头像角标从圆点变为带文字的小药丸（≤16 字符）。

## Changed
- 特殊限制频道（restricted / restriction_reason）现在与 noforwards 区分：限制内容频道显示橙色（顶栏标题+色条+聊天列表名字），noforwards 保持紫色；banned 仍为红色。
- 网页预览附件视频（webDocument）现在把真实文件大小写进文档数据（此前硬编码 0），大小徽章随 attributes 里的时长/分辨率一起显示。

## Fixed
- 主聊天窗口右键"显示文件夹"此前几乎永远不出现（只认 DocumentData 内部路径，而下载管理器落盘不写回该路径）：现在有 sexcat 下载记录（即使文件已被移动）也显示；记录的文件还在时可直接打开所在文件夹。
- MTP 封包工具显示上限从 8192 提升到 16384 字（12737 字的包可整包显示，不再中途截断）。

## Known Limits
- "服务器禁止转发"与 AyuGram 本地禁转仍是同一数据位（紫色）；上游 NoForwards 橙色位保持清除（绕过官方保存限制的既定设计）。
- 网页预览里不带 attributes 的纯链接视频依旧无时长/分辨率（服务端未下发）。
