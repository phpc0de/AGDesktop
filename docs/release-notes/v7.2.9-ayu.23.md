# v7.2.9-ayu.23

## Added
- 视频批量下载选择器：含多个视频的相册/多选下载时，右键弹出选择列表（逐个勾选、显示序号与大小），一次确认整批落盘；全部取消勾选时提示不下载。
- 下载历史失效记录折叠分组：灰色丢失行沉底收进 "Lost records (N)" 分组，双击展开/收起，右键菜单对分组行跳过。

## Changed
- 保存写点命名统一（ADR-0006 Amendment 1）：保存/另存为/批量保存全部经过同一目标校正管道（字幕话题名、裸数字名扩展、重复秒跳过 + toast 提示），此前只有部分路径吃到。

## Fixed
- 特殊限制频道红色 tint 在列表/顶栏"过一会儿就没了"：Forbidden 旗标被全量频道数据更新抹掉（瞬态），现改为持久化客户端旗标，直到频道真正可访问才清除。
- 文件夹视图下本地标签 chip 底部被裁约四分之一、大写字母失下横读成乱码（"NRFAD"）：行高与绘制的标签判定不一致，现保持一致，chip 完整可读。
- 长名字行认证徽章压住静音图标/检查点标记（AG n/m 被盖左半）：badge 改用绘制宽度定位，与静音/标记共用同一定位游标。
- 下载的文件改名后 File name 列不更新：Relink 现同步更新 file_name。
- 下载历史手动 Relocate 产生重复行：SHA 校验通过后改走 Relink 更新原行，不再插入新行。
- 移动文件到之前存过的目录未自动找回：搬迁候选目录追加数据库近期记录的目录，shell 监听根补 Documents。
- 编译审计修复：`Ui::FormatSizeText` 限定名缺失（上一批次唯一必现编译错误）及 3 项审计发现（lang 复数键、双击展开二次翻转、显式符号转换）。

## Known Limits
- 跨盘移动文件 shell 通知无法捕获，仍需在下载历史右键 Relocate 指认一次。
- 本地标签/检查点标记为纯本机功能，官方客户端不可见。

## Internal
- AyuForbidden 持久化旗标：ChannelDataFlag 1<<61 / ChatDataFlag 1<<30，channelForbidden/chatForbidden 置位、可访问时清除。
- 四路并行静态编译审计（7c1a6e1..HEAD 全量）：1 error + 3 warning 全修复；交付文档 docs/delivery-qqq1-q3-q10-q20.md。
