# v7.2.9-ayu.22

## Added
- 聊天列表本地彩色标签：右键任意对话/频道 → "Set local tags" 子菜单，可设置自定义文字标签（空格分隔多个），列表行显示与官方分组标签同款的彩色 chip，支持随时清除；仅本机生效，不与服务器同步。
- 下载条右键菜单新增 "Cancel all downloading"：一键取消全部进行中的下载。
- 多选文件/相册后 "Save all album files as…/Save selected as…"：弹出一次文件夹选择即整批落盘。
- 保存带字幕的视频时用字幕内容修正文件名（裸数字 id → 字幕中的话题标签），并新增 sow list 右键菜单（保存字幕/光标处话题标签、给消息套用已存标签）。
- 视频消息左上角信息补全：未完整加载的视频也显示时长/分辨率/大小角标，下载中叠加实时大小。

## Changed
- 底部消息种类标记从 emoji 前缀改为文字名（视频/GIF/语音/音乐/文件/图片/圆片）。
- sexcat 历史窗口工具栏重排：筛选/搜索/刷新合并一行，扩展名过滤独立一行；表格随数据库新增记录实时刷新。
- 自动找回被移动的已保存文件更激进：监听窗口 5s→20s、目录深度 2→4、单次扫描上限 2000 条；系统下载目录为空时回退 DownloadLocation。
- 徽章配色对齐服务气泡样式；saved 图标改为填充型渲染（旧描边型在样式代码生成下渲染为空）。

## Fixed
- 特殊限制频道（"显示不可用频道"呈现的那批 channelForbidden）在聊天列表与顶栏名字不变色：Banned 判定被 date 守卫挡死（forbidden 路径 date 恒为 0），现正确显示红色。
- 高亮/悬停行的名字颜色优先级盖过限制频道 tint：现在 tint 优先。
- 检查点标记（AG <id>/<ckpt>）在长名字下被挤压裁剪：现在预留宽度、放不下时省略号截断，不再画进日期底下。
- CI：每个 tag 双跑两遍完整 Windows 构建（自发布触发的 release 事件未被防重入标记拦截），现只跑一遍。

## Known Limits
- 本地彩色标签为纯本机功能，官方客户端不可见。
- "显示不可用频道"仅是本地展示绕过；账号仍受同样的服务端限制。

## Internal
- 第二轮静态编译审计修复：补 `rpl/event_stream.h`、`QtWidgets/QApplication` 缺失 include；AyuGram include 块规范化。
