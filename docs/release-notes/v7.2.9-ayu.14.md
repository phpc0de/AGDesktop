# v7.2.9-ayu.14

## Added
- 聊天列表行名字按限制状态着色（与顶栏同源五态）：banned 红、禁转/本地限制紫、私聊对端禁转橙、我方禁转蓝；选中/高亮行保持原配色。
- 下载历史窗口顶部新增后缀过滤：文本类复选框（txt/md/pdf/epub/mobi/azw3/fb2/doc/docx/rtf/xlsx/pptx/csv）、图片类复选框（jpg/jpeg/png/webp/gif/bmp/heic/heif/tif/tiff/svg/avif）、自定义后缀输入框（逗号分隔）；并集过滤，未勾选时行为不变。
- 主聊天窗口消息右键新增"保存 #标签 / 选中文字到母猪列表"（此前只有媒体列表有该入口）。

## Changed
- 聊天列表 AG 检查点标记改为纯文本 "AG 当前位置/检查点位置"，不再依赖特殊符号字形；长名字会自动为标记预留空间；群聊同样显示（此前仅频道）。
- 相册（多图/多视频消息）里每个成员各自显示"已下载"徽章，不再只标第一张。
- 有下载记录但文件已被移动/删除时，消息右键仍显示"显示文件夹"（禁用态，便于发现记录在、文件丢了）。

## Fixed
- 聊天列表检查点标记显示为乱码/部分被裁（U+23F1 字形缺失回退导致）。
- 下载开始瞬间（pending 行）误点亮"已下载"徽章并清空徽章右键的路径。
- 下载目录内移动/改名文件不再漏事件：shell watch 现在同时监听下载目录（此前只监听桌面树），自动重定位命中率提升。
- MTP 封包工具截断提示现在附带完整导出指引（Copy ALL / Ctrl+Shift+C）。

## Known Limits
- 频道/群的"服务器禁止保存"与 AyuGram 本地限制同为紫色（数据上是同一位，不恢复上游限制位以免复活官方保存限制）。
- round 视频、TTL 遮罩消息不画"已下载"徽章（设计使然）。
- 网页预览中的纯 webDocument 视频仍无时长/分辨率徽章（服务端不下发该数据）。
