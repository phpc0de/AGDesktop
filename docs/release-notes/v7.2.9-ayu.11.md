# Release Notes — v7.2.9-ayu.11

基于上游 v7.2.9 + AyuGram 功能层。Tag：`v7.2.9-ayu.11`。
本版是 v7.2.9-ayu.10 发布构建连续失败后的首个成功构建，包含 SexCat 溯源套件的全部收尾修复。

## 下载

- 产物：`AyuGram_7.2.9-ayu.11_win64_portable.zip`（单可执行文件，解压即用）
- 校验：`sha256sums.txt`
- 构建：GitHub Actions（windows-2022 / MSVC v143 / Qt 5.15.19 静态）

## 新增（Added）

- **SexCat 下载溯源套件**（随本构建首次完整上线，详见 v7.2.9-ayu.10 说明）：
  - 下载历史窗口"扫描文件夹"补录：递归为旧下载补算 SHA、写入 NTFS ADS，命中已记录内容自动重链来源。
  - **「已保存」徽标扩展到照片消息**：气泡内照片右上角同样显示角标，hover 提示与右键菜单（打开文件夹 / 查看历史 / 重新验证）行为一致。

## 修复（Fixed）

- **发布构建连续失败（v7.2.9-ayu.10 起四连败）**，三处根因均已修复：
  - 语言包生成器（codegen_lang）拒绝在非复数键上使用 `{count}` 复数 tag（`error 806: plural tag 'count' used in non-plural key 'lng_sexcat_scan_progress'`）——扫描进度文案改用 `{processed}`，调用点同步。
  - `sexcat_folder_scan.h` 引用了上游 lib_base 已删除的 `base/lambda.h`（`error C1083`）——删除该冗余 include，`Fn<>` 由已包含的 `base/basic_types.h` 提供。
  - `sexcat_history_window.cpp` 的 `QComboBox::currentIndexChanged` 在 Qt 5.15 下有 int/QString 两个重载，直接取地址歧义（`error C2665`）——改用 `qOverload<int>` 消歧。
- **SexCat 代码审计修复**：命名空间错误、不完整类型、图标绘制等，见提交 `376d63eb1f`、`7477ba2ffd`、`410e4b348e`。
- **CI 加固**：链接器 OOM 增量重试（/m:1 收敛）、构建期 pagefile 扩容、构建计时与编译错误汇总。

## 已知限制（Known Limits）

- 同 v7.2.9-ayu.10：本套件之前的旧下载没有哈希记录，无法被"重新定位/验证"链路对应。
- exFAT/FAT32 无 NTFS ADS，走侧车文件；侧车与文件分离移动后需手动"重新定位"重连。
