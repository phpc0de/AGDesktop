# v7.2.9-ayu.43

## 另存为入口自证：弹窗+日志双重定位
- 任何"另存为"入口（大图窗口、消息右键保存图片、外部查看器、Ayu 消息历史）现在都会立即弹一条提示（`sexcat <入口> (msg id)`），同时写一行日志 `save entry: <入口> ctx=msg<N> enabled=0|1`——保存对话框一打开就能证明哪个入口在跑、hook 是否开启、上下文消息是哪条。
- 照片另存为的全部三个静默跳过分支（hook 关闭 / 找不到来源消息 / 简介标签为空）现在都会写日志：对话框默认名仍是 photo+日期时，日志直接给出理由。
- 补齐最后两个没有语法名预填的照片存盘口：外部查看器（开启"External media viewer"后点击照片直接存盘）与 Ayu 消息历史窗口的照片另存为——两处现在与消息右键、大图窗口一致使用语法名。
- 每次另存为弹一条提示属于诊断期设计，根因定位后将收敛。
