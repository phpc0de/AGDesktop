# v7.2.9-ayu.29

本版取代构建失败的 v7.2.9-ayu.28（该 tag 无产物），应用代码与 v7.2.9-ayu.27 完全一致（无功能变化）。

## Internal
- v7.2.9-ayu.28 的 prepare 在 jom 解压处失败：workflow 的 pwsh 步骤把 PowerShell 7 的模块目录带进 PSModulePath，命令行里的 Windows PowerShell 5.1 自动加载到了 PS7 版 Microsoft.PowerShell.Archive，其 3 参 ExtractToDirectory 在 .NET Framework 上不存在（MethodCountCouldNotFindBest）。
- jom 解压改用系统自带 bsdtar（tar -xf 直接读 zip）；至此 prepare 流水线 Windows 侧完全不经 PowerShell 下载或解压，此类环境故障整类根除。
- .28 的其余修复保持不变（curl 下载、silent 续跑、稳定缓存 key、摘要降噪）；本次重跑将命中 .28 存下的部分缓存，从 jom 阶段继续，不再全量。
