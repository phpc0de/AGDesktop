# v7.2.9-ayu.30

v7.2.9-ayu.29 之后首个功能版本，sexcat 三项。

## 下载管理
- 消息右键下载组：一条消息的全部进行中下载可一键取消，组进度合并为单个转圈（Q50）。
- 下载历史按"来源消息气泡"归组：同一条消息/相册的文件收进一个可折叠组；旧记录浏览过后自动回填补齐归组（Q35）。
- 下载历史加入勾选框：行勾选 + 组头三态勾选，顶部"Delete checked"按钮实时显示勾选数，可跨组勾选（Q35.1）。
- 新增下载历史回收站：删除记录一律先进站内回收站（不再直接销毁），可勾选恢复或永久删除；重复下载已删除的文件时，完成后提示"以前下载过"（Q36）。
