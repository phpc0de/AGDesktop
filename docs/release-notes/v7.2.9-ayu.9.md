# Release Notes — v7.2.9-ayu.9

基于上游 v7.2.9（全量合并 1226 个上游提交）+ AyuGram 功能层。Tag：`v7.2.9-ayu.9`（head `1fb1f4caae`）。

## 下载

- 产物：`AyuGram_7.2.9-ayu.9_win64_portable.zip`（单可执行文件，解压即用）
- 校验：`sha256sums.txt`
- 构建：GitHub Actions（windows-2022 / MSVC v143 / Qt 5.15.19 静态）

## 新增（Added）

- **MTP Devtools 真实 TL 解码**（替换纯 hex dump）：
  - 由 `api.tl` + `mtproto.tl` 生成的 scheme 表（2345 个构造器，`ayu/debug/mtp_scheme_table.h`，生成脚本 `gen_mtp_scheme_table.py`）。
  - 详情面板以缩进 TL 树渲染数据包；未知构造器自动降级为原始 hex，不再报错。
  - `user_id` / `chat_id` / `channel_id` 字段标注解析出的 peer 名称；`file_reference` 等字节段以可读 hex 显示；字符串反转义。
  - 列表行显示真实构造器名（自动解包 `message` / `msg_container` / `rpc_result` 传输封装）。
  - 新增编解码对 `ayu/debug/mtp_tl_codec.{h,cpp}`（解码 + 重编码）。
- **编辑与重放重写**：编辑打开解码后的 TL 树；flags 位根据实际出现的可选字段自动重算，然后重发包。Replay / Edit & Replay 的成败均写入 `[mtpdev]` 日志。
- **显示不可用频道**设置（AyuGram 设置 → 筛选器）：本地绕过"违反服务条款"横幅，受限频道可正常打开查看。
- **Raw Console 提示与对话框**：devtools 全部按钮带说明；无法适用的行（响应、错误）禁用 Replay / Edit & Replay，并在 TL 编辑器内给出操作指引。
- **跟随上游 v7.2.9**：合并官方 7.2.9 世代全部 1226 个提交（含 IV 编辑器、界面与性能更新、安全修复）。

## 变更（Changed）

- **零成本转发（解除 noforwards）基于原始 MTP 重写**：
  - 相册按 `groupId` 分组，一次 `messages.sendMultiMedia` 发送，转发相册保持一个相册。
  - 不再乐观插入本地消息：服务器确认后才显示（在 done 回调里 applyUpdates），失败的发送不再留下重启才消失的转圈幽灵。
  - 逐单元 done/fail 日志（`zerocost media ok/FAILED`、`album ok/FAILED`、`fallback full items=N`）；`sent` 只计服务器确认数。
  - 被服务器拒绝的单元自动整包回退（下载 + 重上传），内容始终能落地。
- **Devtools 选中稳定性**：点击行固定详情面板；实时流量不再抢走光标下的内容。新增 `Hex` 开关查看原始 32 位字。

## 修复（Fixed）

- **启动闪退（Checkpoint 索引顺序）**：sqlite_orm 逆序执行 schema 对象，Checkpoint 的索引先于建表执行，`no such table` 异常直接杀死启动；索引移到建表之前，初始化恢复路径加兜底，schema 异常不再拦死启动。（曾被崩溃保护改名的 `tdata/ayudata.db` 不会自动迁回，新版会新建库。）
- **启动断言 `!_accounts.empty()`（main_domain.cpp:201）**：MTP devtools 解码/重放路径在账户尚未注册时读取活动账户；现按上游模式以 `domain.started()` 守卫，无账户时优雅降级。
- **文件夹标签开关被服务端打回**：`messages.getDialogFilters` 的 `tags_enabled=false` 每次刷新都覆盖本地强制值；现取两者逻辑或，远端无法再关掉。
- **转发单个相册被拆成多条消息**（见变更）。
- **转发的视频无限转圈、重启后消失**（见变更）。
- **Devtools `core_message` / `ERROR_SCHEME_BAD_CONS` dump 失败**（见新增）。
- 自审修复：`Api::EntitiesToMTP` 参数类型、`mtpc_boolTrue`/`mtpc_boolFalse` 常量、相册分组中前一单元为文本时的空指针、缺失的 `<QtGui/QFontDatabase>` include、无用辅助函数清理。

## 已知限制（Known Limits）

- 受保护媒体的 `CHAT_FORWARDS_RESTRICTED` 由服务端执行；客户端无法绕过，现走"零成本优先、失败自动整包重传"策略。
- "显示不可用频道"仅是本地展示绕过；账号仍受同样的服务端限制。
